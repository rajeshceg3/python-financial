# Offline regression and distribution
## Sub-features
Health/workout correlation and OLS regression plot; random normal histogram.
## How to get to it (user POV)
Run linear_regression.py or np_normal_distribution.py from the repo root with required packages and datasets.
## Driving it with drive.py
Drive executes both real scripts. Correlation must equal independently calculated dataset correlation; model outputs finite. Distribution contains1000finite samples. Plots saved as evidence and inspected.
## Gotchas
OLS correlation is not causation or health advice. Random distribution results vary. Agg is an explicit headless output path, not interactive desktop-window verification. Other datasets are not exercised.
